<!-- Adapted from Anthropic's frontend-design skill. This version revises the design guidance and adds an existing-UI workflow. License terms are in LICENSE.txt. -->

Start with the audience, their primary task, the brief, and existing brand or design system. Choose a visual direction that supports the task. Carry it through typography, layout, color, spacing, and any interaction that benefits from motion. Favor clear hierarchy and useful content. Use familiar controls where they make the interface easier to use.

For an existing UI, inspect the current screens and shared components first. Preserve behavior and established patterns unless the brief calls for a change. Fix unclear interactions, accessibility problems, and missing loading, empty, or error states in the affected flows before cosmetic changes. Reuse available tokens and components.

Check relevant layouts at narrow and wide widths. Check keyboard navigation, visible focus, readable contrast, and key states. Keep motion purposeful and respect reduced-motion preferences. Verify the affected flow when changing an existing interface.
