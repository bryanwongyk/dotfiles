Read the existing brand, screen brief, and `DESIGN.md` when present. Use the [template](references/DESIGN.template.md) to produce one project `DESIGN.md`. Preserve established design choices and omit sections that do not apply.

Use the [DESIGN.md specification](https://stitch.withgoogle.com/docs/design-md/specification) for YAML tokens and section order. Give Stitch concrete tokens and component behavior. Check the contrast of each named text and surface pair, retain visible focus, and specify reduced motion when there is animation. Treat the example values as defaults you can replace to fit the brief.
